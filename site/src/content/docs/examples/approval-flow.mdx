The first rule makes every `production.deploy` wait for a release manager. The second requires two distinct approvers, one release manager and one security reviewer, for merges in production. Combine it with separation of duties:

```yaml
approval:
  separationOfDuties:
    enabled: true
    rules:
      - actorCannotApproveOwnAction: true
```

See [Human approval](/governance/human-approval/) and [Separation of duties](/governance/separation-of-duties/).
