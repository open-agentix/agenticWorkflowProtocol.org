The examples are valid against the current JSON Schema and are checked by the conformance suite. They are rendered from [`spec/v1alpha1/examples/`](https://github.com/open-agentix/agenticWorkflowProtocol.org/tree/main/spec/v1alpha1/examples), so the site and the specification cannot drift apart. All names, hosts and addresses are fictitious (`example.com`).

- [Vulnerability fixer](/examples/vulnerability-fixer/): agents, MCP tools, a command step, budgets and permissions.
- [Invoice processing](/examples/invoice-processing/): data classification and residency.
- [EU data residency](/examples/eu-data-residency/): a reusable policy.
- [Approval flow](/examples/approval-flow/): a policy that requires human approval.
