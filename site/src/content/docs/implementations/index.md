AWP is a specification, not a platform. OpenAgentix is one implementation.

## Platforms which support AWP

| Implementation | Status |
| -------------- | ------ |
| [OpenAgentix](https://github.com/open-agentix/open-agentix) | Reference implementation, **in progress**. Not yet conformant to any profile. |

No other implementation is listed. This list changes only when a project states its support publicly.

## Call for implementations

AWP is not tied to OpenAgentix. If you build a runtime, validator or tool that implements AWP, open an issue or pull request in the [repository](https://github.com/open-agentix/agenticWorkflowProtocol.org) to be listed. Listing requires a public statement of the supported conformance profiles.

- [Conformance profiles](/implementations/conformance/)
- [Build your own AWP runtime](/implementations/build-your-own-runtime/)
